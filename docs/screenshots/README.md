# Screenshot Checklist

No generated or mock screenshots are included. Capture the real running application at 1440×900 or 1920×1080 with browser zoom at 100%. Use the synthetic demo dataset and hide tokens, email addresses, local paths, provider keys, browser extensions, and unrelated tabs.

| File | Capture |
|---|---|
| `01-login.png` | Clean login/register view and DataPilot branding; no real account details |
| `02-dataset-list.png` | Dataset workspace with the synthetic sales dataset |
| `03-dataset-detail.png` | Dataset name, shape, navigation tabs, and a small preview |
| `04-profile-overview.png` | Row/column summary, semantic types, quality score, and correlation summary |
| `05-profile-columns.png` | Several representative numeric, categorical, and datetime column profiles |
| `06-analysis-lab.png` | A completed structured analysis with operation trace and bounded result |
| `07-chart-gallery.png` | At least two genuine charts created from the demo dataset |
| `08-ai-analyst.png` | Question input and validated plan (requires configured LLM) |
| `09-agent-execution.png` | Expanded step statuses, dependencies, attempts, observation, and timing |
| `10-report-viewer.png` | Final evidence-backed report with findings, limitations, and artifact links |

Keep a consistent dataset and browser size across the sequence. Do not edit results into the UI or claim an LLM flow was executed when it was not.
