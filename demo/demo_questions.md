# Demo Questions for `sales_demo.csv`

All questions match the dataset fields. They are prompts, not prewritten conclusions.

## Easy

1. 按地区统计销售额总和。
2. 哪个地区的利润总额最高？
3. 按产品统计销量和销售额。

## Intermediate

4. 各产品类别的销售额、利润和利润率表现如何？
5. 按月份汇总销售额和利润，并比较变化趋势。
6. 销售额与利润之间是否存在明显关系？请给出计算依据。
7. 生成各地区销售额的柱状图。

## Agent workflow

8. 分析不同地区的销售表现，找出需要关注的地区，并说明证据和局限。
9. 比较产品类别的销售额、销量和利润，并生成合适的可视化。
10. 总结这份数据中值得关注的业务现象，给出分析步骤、关键发现和证据引用。

The file contains only six synthetic rows, so trend and correlation findings are demonstrations rather than statistically robust business conclusions.
